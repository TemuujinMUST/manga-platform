# Бидний анхны төсөл
Энэ бол бидний Программ хангамж хөгжүүлэлтийн процесс хичээлийн анхны төсөл.

## Багийн гишүүд
- Тэмүүжин (Product Owner)
- Анхбаяр (Scrum Master)
- Төрболд (Хөгжүүлэгч)
- Тэмүүжин (Хөгжүүлэгч)
- Анхбаяр (Хөгжүүлэгч)

## Төслийн зорилго
Энэ төслөөр бид Scrum аргачлалыг дагаж, жижиг веб аппликейшн хөгжүүлэх болно.
